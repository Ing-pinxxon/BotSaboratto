1. Cliente envía mensaje WhatsApp

El cliente escribe desde WhatsApp. Puede llegar en varios fragmentos rápidos (tipeo por palabras). Meta o Kapso entregan el mensaje al webhook como HTTP POST.

Meta Cloud APIKapso webhook
🔄

2. POST /webhook — Parser dual

El servidor detecta automáticamente si el formato es Meta Cloud API o Kapso, extrae texto, número de teléfono y nombre del remitente.

src/routes/webhook.jssrc/middleware/validation.js
⏱️

3. MessageBuffer — Acumulación 10 segundos

El texto se añade al buffer del usuario. El timer de 10 s se reinicia con cada nuevo fragmento. Esto agrupa mensajes enviados rápido antes de procesarlos.

src/utils/buffer.jsdebounceMs: 10 000
🔍

4. processBuffer() — Validaciones previas al AI

Tras 10 s de silencio se ejecutan chequeos en orden. El flujo se corta en el primer caso que aplique.

Caso A — ¿El usuario ya confirmó pedido hoy?
SI → ignorar silenciosamente (bloqueo diario) NO → continúa ↓
Caso B — ¿Mensaje corto de confirmación? (≤30 chars: "ok / sí / listo / dale / de una / confirmado…")
SI → enviar mensaje de cierre + bloquear usuario hoy NO → continúa ↓
config/bot.config.jsuserState Map
🕐

5. schedule.service.js — ¿Abierto o cerrado?

Se consulta la hora actual en America/Bogota y el horario semanal configurado. El resultado define qué prompt de AI se usa.

Resultado según horario:
OPEN → carga skills/open.md (menú + reglas completas) CLOSED → carga skills/closed.md + inyecta [PROXIMO_DIA] [PROXIMA_HORA]
src/services/schedule.service.jsconfig/skills/
🤖

6. ai.service.js — Gemini genera la respuesta

Se crea una sesión de chat Gemini con el historial del usuario (máx 60 entradas). El skill open/closed actúa como system instruction. Gemini responde en español siguiendo las reglas del negocio.

src/services/ai.service.jsgemini-2.5-flash-liteChatHistory

8. Actualizar historial + detectar estado

El par usuario/modelo se guarda en ChatHistory. Se revisa si la respuesta del AI contiene "Total:" — señal de que el bot presentó un resumen completo de pedido.

¿Respuesta contiene "Total:"?

9. hooks.js — ¿Reenviar a la cocina?

Solo si el bot está ABIERTO: shouldForward() revisa que la respuesta tenga "Total:" y que el mensaje del usuario no sea solo una confirmación.
